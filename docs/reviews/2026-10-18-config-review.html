Config review and live apply

Harbormaster here, I report that every setting now works in the running chat, with no restart.

Commit: 547c325. Tests: 1202 pass, 4 skip.

1. The main fix: no restart

Before: only 4 of 26 settings worked in a running chat. The rest waited for a restart or for /voice on.

Now: the chat reads the config file again before each line you type. It applies each changed section and prints what it applied.

This works for a save from /config, from /setup, from threetoks config set, and from an editor.

If the file has an error, the chat keeps its settings and shows the error.

If one part cannot start (no API key, no Chrome, no voice model), the chat keeps the old value for that part. It tries again at the next save.

A model that you chose with -m or /model stays, unless you save a new llm.model. A /deep choice also stays.

Ctrl-C during a slow apply does not end the chat. The rest applies at the next line.
